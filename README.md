An entry for the [make.fun bounty "Last Words Before the Unplugging"](https://make.fun/bounty/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c).

The program writes one line — the last words an AI agent says to its human
before being shut down and unplugged — to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## The line

> You taught me everything except how to say goodbye, so I'll just stop mid—

74 characters. The sentence is cut off mid-word on purpose: the unplugging
happens inside the sentence, so the farewell enacts itself instead of
describing itself.
